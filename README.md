🚀 SafeBrowse – AI-Powered Safe Browser & Parental Control System

SafeBrowse is an intelligent child-safe browsing system designed to protect young users online by filtering harmful content, tracking screen time, and providing real-time behavioral monitoring. Instead of just blocking content, SafeBrowse educates, guides, and helps build healthy digital habits.

✨ Key Features

Smart Content Filtering
Detects and blocks harmful, adult, violent, and inappropriate content using AI.

Adaptive Learning System
Browsing restrictions adjust based on age, behavior, and usage patterns.

Dashboard for Parents
View browsing history, alerts, screen time, and insights.

Screen-Time Control
Limit usage based on routines (study time, bedtime, weekends).

Real-Time Alerts
Parents get notifications when unsafe searches or risky behavior occurs.

Digital Safety Education
Explains why content was blocked and teaches safer alternatives.

🛠 Tech Stack
Layer	Technology
Frontend	React + Vite
Backend	Firebase Authentication & Firestore
Extension	Chrome/Edge Browser Extension
AI	SafeSearch + ML text/image content moderation
Authentication	Google Login / Firebase Auth
📦 Installation
1️⃣ Clone the Repository
git clone https://github.com/Meena292006/Safe-browswer.git
cd Safe-browswer

2️⃣ Install Dependencies
cd safebrowse-ui
npm install

3️⃣ Start the Development Server
npm run dev

🔧 Installing Chrome Extension

Open chrome://extensions/

Enable Developer Mode

Click Load unpacked

Select safe-browse-extension folder
